### 🚀 Projects

#### 🧠 [1KB SRAM — RTL to GDSII](https://github.com/MuraliVhanmani/1KB_SRAM)
Full RTL-to-GDSII physical design implementation of a 1Kb single-port synchronous SRAM (64 × 16), on a 45nm node using Genus (Synthesis) → Innovus (PnR).

- **Utilization:** 57.24% | **Cell Count:** 1,173
- **Timing:** 0 setup/hold/DRC violations — fully timing clean (WNS 1.167 ns setup)
- **Frequency:** 285.7 MHz | **Total Power:** 0.314 mW

#### 🔢 [chip_top — 32×32 Radix-4 Booth Multiplier](https://github.com/MuraliVhanmani/chip_top)
Full RTL-to-GDSII physical design implementation of a 32×32 Radix-4 Booth Multiplier (MAC: X×Y+Z) with Wallace tree reduction and CLA final adder, on a 45nm node.

- **Utilization:** 65.18% | **Standard Cells:** 42,669 | **Macros:** 16
- **Frequency:** 185.2 MHz
- Full flow from synthesis through routing, clock tree synthesis, and timing analysis
